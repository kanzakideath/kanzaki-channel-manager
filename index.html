Kanzaki Channel Manager

運営者本人の YouTube チャンネル（神崎）専用の、個人用の投稿・分析ツールです。運営者のPC上で動作し、一般公開はしていません。

A private, single-user tool for uploading videos to and viewing analytics for the owner's own YouTube channel. It runs locally on the owner's computer and is not offered to the public.

機能 / Features

  • 自分のチャンネルへの動画アップロード（非公開 → 予約公開） / Upload videos to the owner's channel (private, then scheduled)
  • 字幕・サムネイルの設定 / Set captions and thumbnails
  • 自分のチャンネルの YouTube アナリティクスの確認 / View YouTube Analytics for the owner's channel
