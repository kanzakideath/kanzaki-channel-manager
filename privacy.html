プライバシーポリシー / Privacy Policy

Kanzaki Channel Manager（以下「本ツール」）
最終更新日 / Last updated: 2026-10-21

1. 本ツールについて / About this tool

本ツールは、運営者本人が自分の YouTube チャンネル（UCDXJjS1_Cje1HKm-odYYNmA）に動画を投稿し、そのチャンネルの分析データを確認するための個人用ツールです。一般には公開しておらず、運営者以外のユーザーはいません。

This tool is a private, single-user tool that the channel owner uses to upload videos to their own YouTube channel and to view that channel's analytics. It is not offered to the public and has no users other than the owner.

2. YouTube API サービスの利用 / Use of YouTube API Services

本ツールは YouTube API サービスを使用しています。本ツールの利用者は YouTube 利用規約 に同意したものとみなされます。Google によるデータの取り扱いについては Google プライバシー ポリシー をご覧ください。

This tool uses YouTube API Services. By using this tool, users agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

3. 取得する情報 / Information accessed

  • 運営者本人のチャンネル情報（チャンネル名・ID） / The owner's channel information (name, ID)
  • 運営者本人がアップロードした動画のメタデータ（タイトル・説明・公開設定など） / Metadata of videos uploaded by the owner
  • 運営者本人のチャンネルの YouTube アナリティクス集計データ（視聴回数・視聴時間・登録者数の増減など） / Aggregated YouTube Analytics data for the owner's channel
  • OAuth 認証トークン / OAuth access and refresh tokens

他のユーザーの個人情報は取得しません。 / No personal information of other users is collected.

4. 利用目的 / How information is used

取得した情報は、運営者本人のチャンネルへの動画投稿・公開設定・字幕とサムネイルの設定、および動画の改善のための分析にのみ使用します。

Information is used only to upload and manage videos (visibility, captions, thumbnails) on the owner's channel and to analyze performance to improve future videos.

5. 保存と共有 / Storage and sharing

認証トークンと分析データは、運営者本人のPC内にのみ保存し、アクセス権を運営者のアカウントに限定しています。第三者への提供・販売・共有は行いません。広告目的には使用しません。分析データは取得から最長30日で更新または削除します。

Tokens and analytics data are stored only on the owner's local computer with access restricted to the owner's account. Data is never sold, shared with, or disclosed to third parties, and is not used for advertising. Analytics data is refreshed or deleted within 30 days.

6. Cookie 等 / Cookies

本ツールはウェブサービスではなく、Cookie やトラッキング技術は使用しません。

This tool is not a web service and does not use cookies or tracking technologies.

7. アクセス権の取り消し / Revoking access

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス） からいつでも取り消せます。取り消し後、本ツールは保存済みのトークンを削除します。

Access can be revoked at any time via the Google security settings page. After revocation, stored tokens are deleted.
